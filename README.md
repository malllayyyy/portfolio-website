# Malay's Gamified Portfolio

A static, zero-build-step portfolio website built with HTML, CSS, JavaScript, and Three.js.

## How to Run
- Simply open `index.html` in any modern web browser.
- Or serve locally via terminal: `npx serve .`

## Editing Personal Links
- Edit `index.html` in the `#contact` section to update Email, GitHub, and LinkedIn links.

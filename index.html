BOSS LEVEL

Deployment Platform

A self-built Vercel/Netlify-style PaaS — push a repo, it builds in an isolated container and goes live on a subdomain.

Node.js Express Docker BullMQ Redis PostgreSQL MinIO React Vite Three.js GSAP Socket.IO
  • Full pipeline: clone → isolated Docker build → upload to MinIO → live subdomain via a custom reverse proxy, versioned deployments with one-click rollback
  • Real-time build logs streamed over Socket.IO into a React dashboard with a Three.js hero and GSAP-animated transitions
  • JWT-free custom session auth (stdlib scrypt hashing + HMAC-signed cookies, no auth library), per-user project ownership enforcement
  • Lockfile-hashed build caching (node_modules reuse across builds) and per-project build-time environment variables injected safely via Docker argv (never shell-interpolated)
  • All 6 build phases shipped and verified end-to-end; 13/13 automated tests passing
Local build — repo private for now

ProAcademys

Full ground-up rewrite of a live e-learning platform — legacy PHP to a modern MERN stack, with zero downtime to the original site.

React Vite Tailwind CSS Node.js Express MongoDB Atlas JWT Google OAuth Razorpay
  • Rebuilt a production Laravel/PHP e-learning site as MERN — layered backend (routes → controllers → services → repositories) to eliminate bugs that plagued the original (duplicated payment logic, conflicting routes)

  • Solved a gnarly cross-site cookie auth bug (Vercel frontend + Render backend) with a same-origin API proxy rewrite instead of just cookie flags
